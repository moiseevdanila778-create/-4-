## 1 Введение

Настоящее руководство пользователя описывает работу в информационной системе «МедСтрах» (далее — Система). Система предназначена для автоматизации процессов обработки данных в сфере ОМС.

## 2 Назначение и условия применения

Система предназначена для ведения реестров застрахованных лиц, обработки счетов и формирования отчетности для ТФОМС. 

Для работы с Системой требуется персональный компьютер (или ноутбук), подключенный к сети Интернет, с установленным современным веб-браузером (Google Chrome, Яндекс.Браузер, Firefox версии не ниже 90) и учетная запись в ЦС.

## 3 Подготовка к работе

Перед началом работы убедитесь, что ваше рабочее место подключено к корпоративной сети. Проверьте наличие действующего сертификата электронной подписи (ЭП), если он требуется для выполнения ваших должностных обязанностей.

## 4 Вход в Систему (приложение)

1. Откройте веб-браузер.
2. В адресной строке введите URL-адрес Системы: `https://oms-system.ru` (пример).
3. На странице авторизации введите ваш **Логин** и **Пароль**, выданные администратором.
4. Нажмите кнопку **Войти**.

## 6 Роли в системе

В Системе предусмотрены следующие основные роли:
* Сотрудник СМО;
* Администратор.

## 7 Описание функционала

### 7.1 Роль «Сотрудник СМО»

Сотрудник СМО имеет доступ к следующим функциям:
* Просмотр и редактирование реестров застрахованных лиц.
* Загрузка счетов на оплату медицинской помощи.
* Формирование отчетов по утвержденным формам (например, форма 14-Ф).
* Просмотр уведомлений от ТФОМС.

> **Инструкция:** Для формирования отчета перейдите в раздел **Отчеты** → выберите нужную форму → укажите отчетный период → нажмите кнопку **Сформировать**.

### 7.2 Роль «Администратор»

Администратор обладает полными правами, включая функции Сотрудника СМО, а также:
* Управление учетными записями пользователей (создание, блокировка, сброс паролей).
* Настройка справочников Системы.
* Просмотр журнала действий пользователей (логи).

> **Инструкция:** Для создания нового пользователя перейдите в раздел **Администрирование** → **Пользователи** → нажмите кнопку **Добавить**, заполните обязательные поля (ФИО, Логин, Роль) и нажмите **Сохранить**.
